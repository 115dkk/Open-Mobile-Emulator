# M2 화면 목록

작성 2026-09-26. 구현 전에 어떤 화면을 만들지 정하는 문서다. 기능 명세는 `CLAUDE.md` 5절 M2,
시각 규칙은 `DESIGN.md`, 낱말은 `CONTEXT.md`에 있다. 각 화면은 스냅숏(`AppSnapshot`)의 어느
부분을 그리고 어떤 명령(`Command`)을 보내는지로 정의한다. 목업은 claude.ai 디자인 캔버스에
있고 이 문서의 화면 번호를 그대로 쓴다.

## 0. 창 구조

창은 하나다. 윈도우 기본 캡션 아래에 왼쪽 아이콘 레일(64px)과 본문이 있다. 레일 항목은
`무대`, `앱`, `키`, `표시`, `설정` 다섯 개이고 아래쪽에 게스트 상태 점과 버전이 있다. 첫 실행
마법사(S1)는 레일 없이 본문 전체를 쓰는 별도 상태이고, 마법사가 끝나기 전에는 레일이 보이지
않는다. 기본 크기 1280x800, 최소 960x600. 트레이 아이콘은 항상 있고, 창을 닫으면 게스트가
돌고 있을 때는 트레이로 내려가며 그 사실을 토스트로 한 번 알린다.

## 1. 첫 실행 마법사 (S1)

한 화면에서 단계가 바뀐다. 위에 단계 표시(1/8 형태의 점과 현재 단계 이름), 가운데 단계 본문,
아래 주 버튼과 보조 버튼. 모든 단계에 `나중에 하기`(마법사를 닫고 무대 화면으로 가되 진행
상태를 저장)가 있다. 단계 순서와 건너뛰기 규칙은 `ome-wizard`가 소유한다.

| 단계 | 보이는 것 | 동작 | 규칙 |
|---|---|---|---|
| S1.1 호스트 점검 | 항목별 상태 표. 화면 라벨은 사용자 말로 쓴다: `CPU 가상화`, `Windows 하이퍼바이저 플랫폼`, `다시 시작 대기`, `가상 머신 구성 요소`(QEMU와 펌웨어), `앱 설치 도구`(adb), `디스크 여유`. 각 행은 상태 점 + 이름 + 한 문장 | `다시 확인`, `계속`(Blocked가 없을 때만) | 아무것도 바꾸지 않는다 |
| S1.2 하이퍼바이저 플랫폼 켜기 | 무엇이 바뀌는지 세 문장(윈도우 기능 하나를 켠다, 관리자 확인 창이 뜬다, 재부팅이 필요할 수 있다), 같은 PC의 커널 안티치트 게임과 충돌할 수 있다는 한 문장(KNOWN_LIMITATIONS) | `켜기`(관리자 권한 요청), `지금은 건너뛰기`. Esc로도 나간다 | R9. 이미 켜져 있으면 단계를 건너뛴다. `tcg`로는 진행할 수 없다고 적는다 |
| S1.3 다시 시작 필요 | 재부팅이 필요하다는 안내와 재부팅 뒤 앱을 다시 열면 이어진다는 문장 | `닫기`. 자동 재부팅 버튼은 없다 | R9(예고만 한다) |
| S1.4 게스트 이미지 고르기와 내려받기 | 위에 이미지 프로필 카드(`안드로이드 13` 검증됨 기본 선택, `안드로이드 9`, `안드로이드 15` 등은 검증 상태 표시. 카드에는 버전, 크기, 변환기 종류를 사용자 말로, 검증된 게임 수), 아래에 고른 이미지의 파일 이름, 출처(SourceForge 공식 프로젝트), 크기, 진행률 막대, 속도와 남은 양, 검증 상태(내려받는 중 → 검증 중 → 확인됨) | 카드 선택, `내려받기`, `취소`, 이어받기는 자동 | R2, R10. 매니페스트 밖 URL 없음. 프로필은 `manifests/images/`(ADR-0004) |
| S1.5 게스트 만들기와 설치 | 디스크 크기 선택(32/64/128 GB, 여유 공간 표시), 그 뒤 무대에 설치기가 뜨고 옆에 Bliss 설치 절차 여섯 단계 안내(사용자 조작) | `디스크 만들기`, 설치 끝난 뒤 `설치를 마쳤습니다` | 설치기 조작은 사용자가 한다 |
| S1.6 첫 부팅 | 무대에 부팅 화면, 옆에 진행 문장(가상 머신 시작 → 안드로이드 부팅 대기 → 연결됨 → 기능 확인 중). 능력 조사(ADR-0004)의 항목이 하나씩 확인 표시로 바뀐다. 부팅 뒤 미디어 볼륨 15/15와 기본 표시 프리셋을 적용했다는 문장 | 자동 진행, `취소` | KNOWN_LIMITATIONS(볼륨). 조사에 실패한 능력은 뒤 화면에서 없는 버튼이 된다 |
| S1.7 Google 계정 안내 | 이 기기는 Google 비인증 기기라는 문장, `기기 ID`(GSF 안드로이드 ID, 복사 버튼), 등록 페이지를 여는 버튼(URL 원문은 화면에 싣지 않고 "기본 브라우저에서 google.com의 등록 페이지가 열립니다"라고 적는다), Play 스토어와 인앱 결제가 동작하지 않을 수 있다는 문장 | `등록 페이지 열기`(기본 브라우저, `https://www.google.com/android/uncertified/`), `건너뛰기`, `다음` | R8. 자동 등록 없음. 계정 정보는 이 앱을 거치지 않는다 |
| S1.8 앱 설치 | 파일 놓기 영역(APK, XAPK, APKS), `파일 고르기`, 설치 진행과 결과 | `파일 고르기`(Rust가 대화상자를 연다), `건너뛰기`, `완료` | 게임 이름을 화면에 심지 않는다(R6) |

끝나면 무대 화면(S2)으로 가고 마법사는 다시 나타나지 않는다. 설정에서 `처음부터 다시
설정`으로 되돌릴 수 있다.

## 2. 무대 (S2)

기본 화면이다. 게스트 화면이 놓이는 무대와 그 위 도구 막대, 아래 상태 줄로 이루어진다.

- 게스트 `Stopped`: 무대 자리에 큰 `시작` 버튼 하나와 마지막 실행 시각. 마지막 종료가 비정상이면
  그 사실과 `로그 보기`가 함께 있다.
- `Starting`: 무대는 어둡고 가운데 진행 문장(가상 머신 시작 → 화면 연결 → 안드로이드 부팅 대기).
  `취소`가 있다.
- `Running`: 무대에 게스트 창이 담기고 그 위에 오버레이 창이 표지를 보인다. 도구 막대에는
  `스크린샷`, `볼륨`, `표시 프리셋`, `매핑 표시 켬/끔`, `매핑 편집`, `다시 시작`, `끄기`가 아이콘
  버튼으로 있고, 상태 줄에는 게스트 상태 점, 안드로이드 버전, 해상도와 배율, `앱 관리 연결됨`,
  적용된 입력 프로필 이름(자동 적용이면 전경 앱 이름과 함께), 그리고 일시 중지 중이면 `매핑
  일시 중지 (F12)`가 있다. fps는 기본으로 보이지 않고 설정에서 켠다.
- `Restarting`: 게스트가 재부팅을 요청해 다시 시작하는 중이라는 문장. 무대는 어둡다.
- `Failed`: 무엇이 실패했는지 한 문장, 로그 파일 경로, `다시 시작`, `진단 묶음 내보내기`.
- 창 담기가 실패하면(2안) 무대 자리에 "게스트 화면은 별도 창에 있습니다"와 `창 앞으로`
  버튼이 놓인다.

## 3. 앱 (S3)

게스트에 설치된 앱 목록(아이콘 없이 이름과 패키지, 버전, 설치일), 각 행에 `실행`,
`제거`(확인 대화상자), 위에 `설치`(파일 고르기 또는 끌어 놓기)와 검색. 설치 진행은 목록 위의
한 줄로 보인다. 게스트가 꺼져 있으면 목록은 마지막 값을 흐리게 보이고 동작 버튼은 없다.
스크린샷 저장은 무대 도구 막대에 있고 여기서는 `스크린샷 폴더 열기`만 둔다.

## 4. 입력 (S4)

두 부분이다. 레일의 `입력` 화면과, 무대 위의 오버레이 편집기(ADR-0005).

**입력 화면(S4)**: 왼쪽에 프로필 목록(동봉 프리셋 + 사용자 프로필. 각 행에 이름, 대상 앱 이름,
바인딩 수, 자동 적용 표시), 오른쪽에 고른 프로필의 바인딩 표(입력, 동작 종류, 자리, 설명). 동작은
`새 프로필`, `복제`, `이름 바꾸기`, `삭제`, `대상 앱 지정`(설치된 앱 목록에서 고른다), `무대에서
편집`(S4-오버레이로 간다), `자동 적용` 토글, `일시 중지 단축키`는 설정에 있다. 게스트가 꺼져
있어도 표는 편집할 수 있고 자리는 논리 좌표라 게스트 해상도와 무관하다.

**오버레이 편집기(S4-오버레이)**: 게스트 화면 위에 현재 프로필의 표지가 보인다. `매핑 편집`을
누르면 편집 모드가 되어 위쪽에 도구 띠(표지 종류 다섯 개: 탭, 조이스틱, 스와이프, 마우스 버튼,
휠. 그리고 `저장`, `되돌리기`, `편집 끝`)가 뜨고 클릭이 오버레이로 간다. 빈 자리를 누른 뒤 키를
누르면 탭 표지가 생기고, 표지를 끌어 옮기고, 조이스틱은 반지름 손잡이를 끌어 크기를 바꾼다.
표지를 다시 누르면 홀드 여부, 스와이프 끝점과 지속 시간, 마우스 버튼의 자리(누른 곳 / 고정)를
바꾸는 작은 카드가 뜬다. 편집 모드가 아니면 오버레이는 클릭을 통과시키고 표지는 반투명 칩으로만
보인다. `매핑 표시 켬/끔`으로 표지를 숨길 수 있다. 일시 중지 중에는 표지가 흐려지고 위쪽
가운데에 `매핑 일시 중지 (F12)` 칩이 뜬다(DESIGN.md 8절).

**동작의 종류와 화면 말**: 탭(`누르면 터치`), 홀드(`누르는 동안 터치 유지`, 탭 카드의 토글),
조이스틱(`방향키 넷을 가상 스틱으로`, 기본 키는 WASD 또는 방향키 중 택일), 스와이프(`끌기`),
마우스 버튼(`왼쪽 버튼`, `오른쪽 버튼`, `가운데 버튼`을 `누른 자리` 또는 `고정 자리`에), 휠
(`휠 위`, `휠 아래`를 끌기로), 통과(`게스트로 그대로 보냄`).

## 5. 표시 (S5)

프리셋 카드 세 장(1280x720, 1920x1080, 세로 720x1280)과 현재 값. 각 카드는 해상도, DPI, 방향을
보이고 `적용`을 누르면 게스트 `wm size`/`wm density`를 바꾸고 다음 부팅의 `video=` 인자를
맞춘다. 적용에 재부팅이 필요한 항목은 그 사실을 카드 아래에 적는다. 배율(창에 맞춤 / 1:1)은
여기서 고른다.

## 6. 설정 (S6)

절 제목 아래 설정 행(라벨과 도움 문장 왼쪽, 컨트롤 오른쪽 고정 폭)이 이어진다. 카드 없음.

- 게스트: 메모리(4~16 GiB 슬라이더, 기본 8), `프로세서 코어`(vCPU, 2~8, 기본 4), `그래픽`(기본은
  하드웨어 가속이라고 적고, 소프트웨어 렌더링은 문제 해결용 토글), 창 닫을 때 동작(트레이로 /
  게스트 끄기).
- 게스트 이미지: 만든 게스트 목록(이름, 안드로이드 버전, 디스크 크기, 마지막 실행, 확인된 기능
  수)과 `시작할 게스트`, `새 게스트 만들기`(S1.4의 이미지 카드와 디스크 크기 선택을 대화상자로),
  `게스트 삭제`(디스크 파일까지 지운다는 확인). 이미지 프로필 목록은 갱신으로 늘어난다는 문장.
- 입력: `매핑 일시 중지 단축키`(기본 F12, 키 하나 눌러 바꿈), `매핑 표지 기본 표시`, `게임별
  자동 적용` 토글.
- 저장 위치: OME 홈 경로와 `폴더 열기`, 디스크 사용량.
- 업데이트: 현재 버전, `업데이트 확인`, 새 버전이 있으면 버전과 릴리스 노트 링크와
  `내려받아 설치`(서명 검증 뒤에만 설치, 사용자가 누를 때만). 자동 확인 켬/끔.
- 진단: `진단 묶음 내보내기`, `로그 폴더 열기`, 최근 이벤트 다섯 줄.
- 정보: 제품 이름과 버전, 라이선스(GPL-2.0-or-later), 제3자 고지, QEMU 소스 제공 링크,
  `처음부터 다시 설정`.

## 7. 트레이와 알림 (S7)

트레이 메뉴: `창 보이기`, `게스트 시작/끄기`, `종료`. 토스트는 세 종류만 있다. 게스트가 예기치
않게 끝났을 때(`로그 보기` 동작 포함), 업데이트가 있을 때, 긴 내려받기가 끝났을 때. 토스트는
윈도우 알림 센터에 남고 앱은 알림 이력을 따로 두지 않는다.

## 8. 막힘 화면 (S8)

마법사 밖에서도 나올 수 있는 전체 본문 상태. 가상화가 BIOS에서 꺼져 있음(BIOS에서 켜는 방법
안내와 제조사별 키 이름은 적지 않고 문서 링크), QEMU 파일이 없음(다시 설치 안내), 하이퍼바이저
플랫폼이 꺼졌음(S1.2로 가는 버튼). 각 화면은 원인 한 문장, 다음 행동 한 문장, 버튼 하나다.

## 9. 문구와 상태 규칙

- 모든 오류는 `AppIssue`의 문장과 다음 행동을 그대로 쓴다. 원문은 `세부 정보` 펼침 안에만 있다.
- 상태 점 옆 글자는 상태 이름을 되풀이하지 않고 다음 행동을 말한다("시작할 수 있습니다",
  "부팅을 기다리는 중입니다").
- 게임 이름, 캐릭터, 스크린샷은 제품 화면과 목업에 넣지 않는다. 목업의 앱 목록은 "샘플 앱"
  같은 중립 이름을 쓴다(R6).
- 숫자는 `tabular-nums`, 단위는 띄어 쓴다(2.3 GB, 58 fps).

## 9.1 목업

목업은 claude.ai 디자인 캔버스 "OME M2 화면"(https://claude.ai/artifact/7FaX8LfKf7ut25HY1MC13m)에
어두운 테마로 15장 있다(S1.1, S1.2, S1.4, S1.7, S1.8, S2 네 상태, S3~S6, S7, S8). 목업이 이 문서와
다르게 한 것은 다음과 같고, 이 문서는 그 결정을 따른다.

- 내부 이름을 사용자 말로 바꿨다(위 표에 반영). 상태 줄의 adb 연결은 `앱 관리 연결됨`이다.
- S1.4의 파일 이름은 목업에서 중립 이름(`guest-image-x86_64.iso`)이다. 제품은 매니페스트의 실제
  파일 이름을 그대로 보인다.
- 꺼짐, 시작 중, 실패 상태의 도구 막대에는 표시 프리셋과 키 매핑 켬/끔만 있다. 동작하지 않는
  버튼은 비활성이 아니라 없다(DESIGN.md 7절).
- 밝은 테마 목업은 없다. 토큰은 두 테마를 다 갖고 있으므로 구현에서 만든다.
- 캔버스는 1280px 프레임을 축소해 보이므로 휴대폰에서는 핀치로 확대해야 글자가 읽힌다.

## 10. 사용자가 정할 것

1. 레일을 아이콘 + 라벨(64px)로 둘지, 라벨만 있는 넓은 레일(200px)로 둘지. 권고는 무대를
   넓게 쓰는 아이콘 레일이다.
2. 무대에 fps와 호스트 CPU를 상시 표시할지. 권고는 기본 숨김, 설정에서 켬이다.
3. 창을 닫을 때 기본 동작(트레이로 내려가기 / 게스트 끄기). 권고는 게스트가 돌고 있으면
   트레이로 내려가기다.
4. 마법사 S1.7의 구글 안내를 첫 실행에 넣을지, 설정으로 옮길지. R8은 첫 실행 화면에 경고를
   요구하므로 권고는 첫 실행에 둔다.
5. 매핑 일시 중지의 기본 단축키. 권고는 F12(게임이 잘 쓰지 않는 키).
6. 마법사 S1.4에서 처음 사용자에게 보일 이미지 카드의 순서. 권고는 검증된 안드로이드 13을
   기본 선택으로 맨 앞에 두고, 검증되지 않은 세대는 `후보`로 표시해 뒤에 둔다.

목업(9.1절)에는 S4-오버레이, S1.4의 이미지 카드, S6의 게스트 이미지 절이 아직 없다. 위 결정이
나면 그 세 장을 더 그린다.
