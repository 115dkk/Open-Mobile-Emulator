Open Mobile Emulator 0.1.3은 안드로이드 15를 다시 고를 수 있게 하고, 게임 화면을 가리던 기본 키 매핑 표시를 없앤 사전
릴리스입니다. 설치기, 요구 사항, 파일 확인 절차는 0.1.2와 같고(`docs/help/install.md`), 아래에 바뀐 것만 적습니다.

## 바뀐 것

- **안드로이드 15를 다시 고를 수 있습니다('검증 전').** 첫 실행 마법사와 설정의 `새 운영체제 설치`에서 `안드로이드 15`
  카드를 고르면 제품이 이 프로젝트가 직접 빌드한 이미지(`guest-android-15-20261003`)를 받아 설치합니다. 0.1.2에서 이
  프로필을 뺐던 까닭은 BlissOS가 이미지에 넣어 둔 기기 위장 코드였습니다. 부팅 때 빌드 종류와 검증 부팅 상태를 잠긴 판매
  기기의 값으로 덮어쓰고, 앱에게 Pixel이나 다른 휴대폰의 기기 값을 주고, 개발자 옵션을 숨기는 코드입니다. 새 이미지는 이것을
  모두 빼고 빌드했고, 게스트는 있는 그대로(`userdebug`, `test-keys`) 보입니다. 위장 코드가 든 2026-10-02 이미지 릴리스는
  지웠습니다.
- 이 이미지에는 ARM 변환기와 구글 앱이 없습니다. 그래서 ARM 전용 게임은 안드로이드 15에서 돌지 않고, 게임은 지금처럼
  안드로이드 13에서 합니다. 마법사의 기본 선택도 안드로이드 13 그대로입니다.
- **기본 키 매핑을 비웠습니다.** 트릭컬이 앞에 오면 고르는 동봉 프리셋 '기본 입력'에 Space(가운데 탭)와 좌우 화살표
  (스와이프)가 들어 있어, 그 표시가 게임 화면을 가렸습니다. 이제 이 프리셋에는 매핑이 없습니다. 키를 쓰려면 `입력` 화면에서
  프리셋을 복제해 원하는 키를 넣으십시오. 화면 탭 도구 막대의 눈 모양 단추(`매핑 표시`)로 매핑 표시를 끄고 켤 수 있습니다.

## 동봉한 QEMU

0.1.2와 같은 `qemu-v11.1.1-ome5`(패치 0001~0006). 러너가 빌드하고 증명을 붙인 것이며, 대응 소스
`qemu-source-offer-*.tar.gz`를 같은 릴리스에 올립니다.
