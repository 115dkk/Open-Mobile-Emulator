Open Mobile Emulator 0.1.0은 첫 공개 사전 릴리스입니다. arm64 전용 모바일 게임을 윈도우 PC에서 돌리는
에뮬레이터이며, 소스가 공개되어 있고 릴리스 파일마다 어느 커밋과 워크플로에서 나왔는지 증명이 붙어 있습니다.

## 무엇이 들어 있나

- 설치기 `Open-Mobile-Emulator-0.1.0-x64-setup.exe`. 제품, 가상 머신 프로그램(OME 패치를 더한 QEMU 11.1.1),
  UEFI 펌웨어(EDK2)가 들어 있습니다. 운영체제 이미지는 들어 있지 않고 첫 실행 마법사가 공식 배포처(SourceForge의
  Bliss OS 프로젝트)에서 내려받아 SHA-256을 대조합니다.
- 설치기 옆의 `.sha256`, 동봉한 QEMU 런타임 `qemu-ome-*-win64.zip`, 그 QEMU의 대응 소스
  `qemu-source-offer-*.tar.gz`(GPL-2.0 소스 제공), `THIRD_PARTY.md`, `NOTICE`, `LICENSE`, `SHA256SUMS`.

## 할 수 있는 일

- 첫 실행 마법사가 PC 점검, Windows 하이퍼바이저 플랫폼 켜기(동의 뒤 한 번 승격), 이미지 내려받기, 운영체제
  설치(`설치하기`를 누르면 그 뒤는 무인), 첫 부팅, APK 설치를 안내합니다. 설치는 약 30초, 첫 부팅은 약 50초입니다
  (개발 PC 기준).
- 게스트 창은 제품 창 안에 자리 잡고, 해상도와 DPI 프리셋, 주사율과 수직 동기화, 메모리와 vCPU 한도, 키보드와
  마우스 입력 프로필(탭, 홀드, 가상 조이스틱, 스와이프, 오버레이 편집기)을 설정에서 고릅니다. 트릭컬 리바이브
  프리셋이 들어 있습니다.
- APK, XAPK, APKS 설치와 제거, 실행, 스크린샷 저장, 진단 묶음 내보내기, Google 비인증 기기 등록 안내.
- 설정의 `저장 위치` 절에서 데이터 폴더, 스크린샷 폴더, 공유 폴더를 바로 열고, 공유 폴더의 파일을 가상 머신
  내부 저장소의 `OME` 폴더로 보냅니다(한 방향). 설치 폴더는 `정보` 절의 `프로그램 폴더 열기`로 엽니다.

## 확인한 게임

| 게임 | 패키지 | 확인한 버전 | 결과 |
|---|---|---|---|
| 트릭컬 리바이브(국내판) | `com.epidgames.trickcalrevive` | 10644 (2026-09-26) | 설치, 다운로드, 게스트 계정, 튜토리얼 전투, 풀보이스 스토리, 장시간 세션(2시간 40분, 크래시 없음). 전투 58 fps(virgl, 60 Hz) |

이 제품으로 마법사부터 게임 실행까지 가는 완주 기록은 저장소의 `docs/evidence/M2/dod-local.md`와
`docs/evidence/M3/`에 있습니다.

## 요구 사항

- Windows 11(22621에서 개발하고 검증했습니다. Windows 10은 시험하지 않았습니다). WebView2 런타임은 Windows 11에
  들어 있습니다.
- 하드웨어 가상화가 켜진 x86-64 프로세서. 제품은 Windows 하이퍼바이저 플랫폼 위에서 돌며 자체 커널 드라이버를
  설치하지 않습니다.
- 메모리 16 GB 이상 권장(가상 머신 기본 8 GiB), 저장 공간 40 GB 이상.
- OpenGL 2.0 이상의 그래픽 드라이버. 없으면 소프트웨어 렌더링으로 바꾸어 알리는데 그때는 게임이 초당 12~13프레임으로
  느립니다. 검증한 GPU는 NVIDIA GeForce RTX 2080 SUPER뿐이며, Intel과 AMD GPU는 아직 확인하지 못했습니다.

## 설치와 파일 확인

이 설치기에는 코드 서명이 없습니다(인증서 비용을 댈 후원이 생기면 그때 서명합니다). 처음 열면 SmartScreen이
"Windows의 PC 보호" 창을 띄우는데 `추가 정보`를 누른 뒤 `실행`을 누르면 설치가 시작됩니다. 설치기는 관리자 권한
없이 현재 사용자 계정의 `%LOCALAPPDATA%\Open Mobile Emulator`에 설치합니다.

서명 대신 파일을 두 가지로 확인할 수 있습니다. `Get-FileHash <파일> -Algorithm SHA256`으로 나온 값을 `.sha256`과
대조하는 것과, GitHub CLI로 빌드 출처 증명을 확인하는 것입니다.

```
gh attestation verify Open-Mobile-Emulator-0.1.0-x64-setup.exe --repo 115dkk/Open-Mobile-Emulator
```

릴리스의 모든 파일은 GitHub Actions의 윈도우 러너가 태그 커밋에서 빌드했고, 개발자 PC에서 만든 파일은 하나도
없습니다. 자세한 절차는 `docs/help/install.md`에 있습니다.

## 알려진 한계

전체 목록은 `docs/KNOWN_LIMITATIONS.md`에 있습니다. 중요한 것만 적습니다.

- ARM 변환기는 Bliss OS 이미지에 든 Google의 비공개 바이너리(`libndk_translation`)입니다. 이 프로젝트가 만든 것이
  아니며 오픈소스 변환기로의 교체는 출시 뒤 과제입니다. Google이 그 변환기를 싣는 에뮬레이터 이미지의 SDK 라이선스
  계약은 앱 개발 목적에만 사용권을 주고, 게임 실행은 그 범위에 들지 않습니다.
- 32비트 ARM 앱은 비공개 변환기로만 돕니다.
- GPU 가속은 OpenGL(virgl)뿐이라 Vulkan 필수 게임은 미지원입니다. 앱 안의 동영상은 검게 나옵니다.
- 게스트는 Google 비인증 기기라 Play 스토어와 인앱 결제는 등록 절차를 거쳐도 보장되지 않습니다.
- Windows 하이퍼바이저 플랫폼을 켜면 같은 PC의 커널 안티치트 게임과 충돌할 수 있고, 제품은 이 설정을 임의로 바꾸지
  않습니다. 에뮬레이터를 탐지하는 게임은 지원 범위 밖이며 회피 기능은 없습니다.
- 사전 릴리스이므로 제품의 자동 업데이트는 이 버전을 권하지 않습니다. 정식 릴리스부터 권합니다.
- 원격 측정은 없습니다. 크래시 로그는 PC에만 남고, 보내려면 진단 묶음을 직접 첨부해야 합니다.
