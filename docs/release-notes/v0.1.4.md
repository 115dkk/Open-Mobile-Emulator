Open Mobile Emulator 0.1.4는 가상 머신 안의 마우스 포인터가 실제 커서와 다른 자리에 있던 문제를 고친 사전 릴리스입니다.
설치기, 요구 사항, 파일 확인 절차는 0.1.3과 같고(`docs/help/install.md`), 아래에 바뀐 것만 적습니다.

## 바뀐 것

- **포인터가 커서 자리에 옵니다.** 0.1.1부터 0.1.3까지는 안드로이드가 그리는 검은 포인터가 실제 커서 위치의 약 0.6배
  자리에 있었고, 클릭과 터치도 그 자리에서 일어났습니다. 원인은 동봉한 QEMU의 OME 패치 0006이 마우스 좌표를 두 번
  변환한 데 있었습니다. 패치를 고친 QEMU 릴리스 `qemu-v11.1.1-ome6`을 동봉합니다.
- **고른 해상도로 가상 머신의 화면이 뜹니다.** 지금까지는 가상 머신의 실제 화면이 1280x800에 머물고 그 위에 고른 해상도를
  덮어써서, 화면 위아래에 띠가 생기고 그림이 가로로 조금 늘어났으며 포인터도 세로로 어긋났습니다. 이제 시작할 때 표시
  설정의 해상도를 가상 머신의 화면 크기로 넘깁니다. 가상 머신이 켜진 채 가로와 세로처럼 비율이 다른 해상도로 바꾸면 다음에
  시작할 때까지는 띠가 남습니다.

측정과 원인 분석은 `docs/evidence/M3/pointer-alignment.md`에 있습니다.

## 동봉한 QEMU

`qemu-v11.1.1-ome6`(패치 0001~0006, 0006을 고침). 러너가 빌드하고 증명을 붙인 것이며, 대응 소스
`qemu-source-offer-*.tar.gz`를 같은 릴리스에 올립니다.
