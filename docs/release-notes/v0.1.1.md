Open Mobile Emulator 0.1.1은 0.1.0을 쓰면서 나온 창과 표시 문제를 고친 사전 릴리스입니다. 설치기, 동봉 파일, 요구
사항, 파일 확인 절차는 0.1.0과 같고(`docs/help/install.md`), 아래에 바뀐 것만 적습니다.

## 고친 것

- **창을 끌면 운영체제 창이 뒤늦게 따라오던 문제.** 제품이 운영체제 창을 바로 옮깁니다.
- **프리셋으로 바꾼 해상도가 다른 화면에 갔다 오면 되돌아가던 문제.** 동봉한 QEMU에 패치 0006을 더해, 제품 창의
  크기를 운영체제의 해상도로 알리지 않습니다. 해상도는 표시 설정이 정하고 창은 그 화면을 비추기만 합니다.
- **운영체제 안의 마우스 포인터가 실제 마우스보다 위에 떠 있던 문제.** 같은 패치가 마우스 좌표를 화면의 실제 배치
  (가운데 정렬과 여백)에 맞춰 환산합니다.
- **표시 설정의 사용자 지정 해상도.** 입력이 카드 밖으로 넘치지 않고, 지금 값이 채워져 있으며, 폭이나 높이를 바꾸면
  DPI를 제안하고, 적용될 값을 한 줄로 미리 보여 줍니다. 프리셋에 2560x1440, 3840x2160, 세로 1080x1920을 더했습니다.
- **적용한 해상도의 기억.** 제품을 다시 켜거나 운영체제를 다시 부팅해도 표시 설정이 지금 해상도를 보여 줍니다.
- **GRUB 메뉴.** 0.1.0 이전의 설치기로 만든 운영체제는 켤 때마다 GRUB 메뉴가 보였는데, 제품이 한 번에 한해 GRUB 없이
  바로 시작하도록 옮깁니다. 그 첫 시작이 실패하면 이전 방식으로 되돌리고 알립니다.

## 바뀐 것

- **제품이 그리는 제목 표시줄.** 창 위쪽을 제품이 직접 그립니다(끌기, 더블클릭 최대화, 최소화·최대화·닫기).
  Windows 11에서 최대화 단추에 마우스를 올리면 뜨는 스냅 레이아웃 메뉴는 이 판에 없습니다.
- 화면 탭 도구 줄에 위 여백을 두어 해상도 선택 상자가 잘리지 않습니다.
- 레일의 첫 항목 이름이 `화면`입니다.

## 동봉한 QEMU

`qemu-v11.1.1-ome5`(패치 0001~0006). 러너가 빌드하고 증명을 붙인 것이며, 대응 소스 `qemu-source-offer-*.tar.gz`를 같은
릴리스에 올립니다.
