# 가상화 켜는 방법

Open Mobile Emulator는 프로세서의 하드웨어 가상화(Intel VT-x 또는 AMD-V)가 켜져 있어야 동작합니다.
이 기능은 PC의 펌웨어(UEFI 또는 BIOS) 설정에서 켜고 끕니다. 제품은 이 설정을 바꾸지 못하므로
직접 켜야 합니다.

## 지금 상태 확인

작업 관리자(Ctrl+Shift+Esc)의 성능 탭에서 CPU를 고르면 오른쪽 아래에 `가상화: 사용` 또는
`사용 안 함`이 보입니다. `사용`이면 이 페이지의 일은 끝났습니다. 앱에서 `다시 확인`을 누르십시오.

## 펌웨어 설정에 들어가기

두 방법 중 편한 쪽을 쓰십시오.

1. Windows 설정 → 시스템 → 복구 → 고급 시작 옵션의 `지금 다시 시작` → 문제 해결 → 고급 옵션 →
   `UEFI 펌웨어 설정` → 다시 시작.
2. PC를 켜자마자 제조사가 정한 키(대개 Del, F2, F10, F12 중 하나)를 누릅니다.

## 켤 항목

메뉴 이름은 제조사마다 다릅니다. 보통 `Advanced`, `CPU Configuration`, `Security` 아래에 있습니다.

| 프로세서 | 항목 이름의 예 |
|---|---|
| Intel | `Intel Virtualization Technology`, `Intel VT-x`, `VT-x` |
| AMD | `SVM Mode`, `AMD-V`, `Secure Virtual Machine` |

값을 `Enabled`로 바꾸고 저장한 뒤 다시 시작합니다(대개 F10). Windows가 다시 켜지면 앱으로 돌아와
`다시 확인`을 누르십시오.

## 켰는데도 꺼져 있다고 나올 때

- 일부 노트북은 `VT-d`나 `IOMMU`가 따로 있습니다. 위 항목과 함께 켜도 됩니다.
- 회사 PC라면 관리자가 펌웨어 설정을 잠갔을 수 있습니다. 관리자에게 문의하십시오.
- 다른 가상화 프로그램(VirtualBox, VMware)이 자기 드라이버를 쓰고 있어도 이 항목과는 무관합니다.
  이 제품은 Windows 하이퍼바이저 플랫폼을 쓰며, 그 안내는 별도 페이지에 있습니다.
