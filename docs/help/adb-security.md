# adb 연결과 보안

adb(Android Debug Bridge)는 PC의 프로그램이 안드로이드 운영체제를 다루는 표준 통로입니다.
Open Mobile Emulator는 앱 설치와 실행, 스크린샷, 화면 크기 조정을 모두 이 통로로 하므로 adb는
항상 켜져 있고 끌 수 없습니다.

## 주소

설정 → 고급 → adb 연결에 보이는 주소는 `127.0.0.1:5555`입니다. 이 주소는 이 PC 안에서만
닿습니다. Android Studio, scrcpy 같은 도구를 쓰려면 다음처럼 연결합니다.

```
adb connect 127.0.0.1:5555
```

## 같은 PC의 프로그램

adb로 연결한 프로그램은 운영체제 안의 모든 앱과 데이터를 다룰 수 있습니다. 앱을 설치하고, 파일을
꺼내고, 화면을 조작할 수 있습니다. 신뢰하는 프로그램만 이 주소에 연결하십시오. 출처를 모르는
프로그램이 PC에 있다면 그 프로그램도 같은 권한을 얻을 수 있습니다.

## 다른 PC에서 연결 허용

기본값은 끔입니다. 켜면 adb 포트가 이 PC의 모든 네트워크 주소에 열려, 같은 네트워크의 누구나
운영체제에 접근할 수 있습니다. 네트워크에 열린 adb 포트는 실제로 공격받은 적이 있습니다.
2018년의 ADB.Miner는 열린 5555 포트를 찾아 앱을 설치하며 퍼졌고, 한 PC 에뮬레이터의 열린 디버그
포트는 CVE-2018-0701로 등록되었습니다.

다른 PC에서 연결할 일이 없으면 이 설정을 끈 채로 두십시오. 켜야 한다면 신뢰하는 네트워크에서만
잠시 켜고, 일이 끝나면 끄십시오. 이 설정은 운영체제를 다시 시작해야 적용됩니다.

## 루트 권한

설정의 루트 권한 항목은 앱이 루트를 요청할 수 있게 하는 것이며 adb와는 별개입니다. 설치된
운영체제 이미지가 지원할 때만 켤 수 있고, 지원하지 않는 이미지에서는 항목이 비활성입니다.
일부 게임과 결제 기능은 루트가 켜진 기기에서 동작하지 않습니다.
